# 4320 Project 3: Stock Data Visualizer
**_By: Nolan Haag, Carson Hall, David Novencido, Tim Saunders_**

Program for displaying stock graphs in browser from CLI prompts.

Utilizing AlphaVantage API, Pygal, Lxml, and Requests, a user is able to generate a graph by choosing:
1. Stock symbol
2. Bar or line graph
3. Time series (intraday, daily, weekly, monthly)
4. Start and end date
